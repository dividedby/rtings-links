Store links on [rtings.com](https://www.rtings.com) (Amazon, Best Buy, B&H Photo and the
rest) open in a new tab, so the review you're reading stays where it is. Rtings opens them
in the same tab, which loses your place.

**New in 1.4**

- Ctrl/Cmd-click, Shift-click and middle-click are left to your browser again, so "open in
  a background tab" and "open in a new window" work as usual.

**How it works**

- A plain click on any link that leaves rtings.com opens it in a new tab. Links within
  rtings.com work as usual.
- Nothing is sent anywhere: the script only changes how the click opens the link.
